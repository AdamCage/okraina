# Рецепты `<domain>`

Шаги внутри домена. Класс задачи уже выбран process.
Имена файлов — плейсхолдеры; реальные пути — из проектного `AGENTS.md`.

## Новый контур

1. Прочитать проектный `AGENTS.md`.
2. Минимальная раскладка по [layout.md](layout.md).
3. Вписать контур в проектный `AGENTS.md`.
4. Живые доки контура (если домен их завёл).
5. Точечная проверка из проектного `AGENTS.md`.

## Новый шаг существующего контура

1. Сначала логика / модуль, не проводка.
2. Тест на шаг.
3. Проводка.
4. Обновить живую архитектуру контура.

## Отладка красного прогона

1. Системный сбой vs единичная ошибка (как принял домен).
2. (типовые симптомы — заполнить при подъёме домена)
