# Специализация домена evolve

Этот домен живёт только в репозитории канона. Продукт его не
специализирует и не копирует.

## В этом репозитории

Факты — корневой [../AGENTS.md](../AGENTS.md):

- process всегда, evolve — когда меняем канон, game — когда
  меняем тот домен;
- включённые классы и выключенные `deploy` / `incident`;
- гейты на инварианты, переименование входов, удаление домена,
  смену конфликта;
- проверка: dry-run bootstrap, живые ссылки, строка router,
  SKILL-таблица домена;
- GitHub labels/templates этого репо.

Не дублировать эти факты в `evolve/AGENTS.md`. Ссылка.

## В продукте

Не создавать `<project>/evolve/`. Не писать skill «читай evolve».
Контрибьютор канона работает **в этом** репозитории по
[AGENTS.md](AGENTS.md).

## Editor

Если в этом репо есть skill/rule — тонкие указатели на `process/`,
`evolve/`, `game/`. Без копий текстов. Без `.common`.

## Когда расширять evolve, а не process

Сюда — только «как менять канон». Общий цикл, роли, router, GitHub SoR —
в `process/`. Повторять их здесь запрещено.
