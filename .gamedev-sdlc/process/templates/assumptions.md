# assumptions.md — `<контур>`

Неблокеры и принятые допущения. Блокер без accept человека
держит реализацию.

| ID | Допущение | Статус | Кто снял |
|---|---|---|---|
| A1 | | open / accepted / rejected | |

Статус `accepted` — часть контракта, пока не отвергли.
`rejected` — в спеке должно быть явное «не делаем».
`open` — не блокер; если оказался блокером, перенести в вопросы
аналитика, не закрывать самим.
