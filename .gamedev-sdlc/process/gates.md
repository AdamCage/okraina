# Гейты

Стоп, пока человек не ответил. Агент не обходит гейт «временно»
и не пишет «продолжу, вы поправите».

## Всегда спросить

| Действие | Почему |
|---|---|
| Прод-store submit / production track | Необратимо для игроков |
| Force-push, перепись истории, снятие branch protection | Ломает чужие копии |
| Wipe сохранений / live economy / mass revoke builds | Легко задеть игроков |
| Принять аналитические допущения вместо ответа | Это и есть контракт |
| Продолжать после 5 итераций ревью | Скорее спор о цели, чем о коде |
| Выключить стадию процесса | Меняет конфликт слоёв |
| Удалить домен, переименовать вход, сменить правила конфликта | Ломает потребителей `<sdlc-root>` |
| Смена signing / provisioning / store credentials в CI | Секреты и доступ к аккаунтам |
| Публикация GitHub Release с артефактом store | Публичная поставка |

Полный список деструкции не исчерпывающий: если цена ошибки ≥ вопроса —
спросить. Инвариант 7 в [AGENTS.md](AGENTS.md).

## Гейты цикла

| Момент | Кто решает | Снять гейт |
|---|---|---|
| Открытые блокеры аналитики / элаборации | Человек | Ответы в `spec.md` / дизайн-пакете или явный accept пунктов `assumptions.md` |
| Старт реализации | Агент сам | Класс допускает код **и** блокеров 0 |
| Выход из ревью | Ревьюер | `blocker = 0` в [templates/review.md](templates/review.md) |
| Дедлок ревью (>5) | Человек | Решение: меняем контракт / принимаем риск / стоп |
| `release` / `deploy` в прод / store | Человек | Явная просьба в задаче; команды — из проектного `AGENTS.md` |
| `hotfix` на опубликованном контракте канона | Человек | Подтвердить, что ломается потребитель |
| Merge в `main` при required reviews | GitHub + человек | PR checks green, approvals по branch protection |

## Проектные добавки

Корневой `AGENTS.md` потребителя может добавить гейты
(обязательный approve на платформу X, запрет трогать IAP Y).
Канон их не отменяет. Канон не выдумывает продуктовые гейты сам.

## Чего гейтом нет

- Ниты и вкус после первого прохода ревью.
- Выбор диаграммы / схемы из меню аналитики.
- Точечный unit / Godot editor Run на dev.
- Правка текста канона внутри уже согласованного increment
  (кроме breaking entry — см. [../evolve/AGENTS.md](../evolve/AGENTS.md)).
- Создание draft GitHub Issue / draft PR без merge.
