# Принципы процесса

Зачем приняты инварианты из [AGENTS.md](AGENTS.md). Если принцип мешает
случаю — явное исключение в корневом `AGENTS.md` потребителя, не молчаливый обход.

## 1. Класс уже сужает работу

Полный цикл на опечатке сжигает ревью и плодит спеки-фантомы.
Узкий класс (increment, hotfix, review-only) — выбор по умолчанию.
Широкий — когда появляется новый контур, новая механика или новый подход.

## 2. Чат не контракт

Следующий агент не видит переписку. `spec.md`, `assumptions.md` и
(для игрового контура) живой дизайн-пакет — единственный способ
передать границу «сделано / не сделано». GitHub Issue хранит ссылку
на артефакты, не заменяет их.

## 3. Блокер аналитики дешевле, чем откат кода

Реализация на незакрытом вопросе фиксирует догадку в diff-е.
Допущение, которое человек принял, — тоже ответ; его пишут в
`assumptions.md` и снимают блокер.

## 4. Ревьюер с тем же контекстом защищает свою работу

Тот же чат уже «знает», зачем костыль. Новый контекст видит только
контракт и diff. Поэтому ревьюер не патчит; implementer закрывает пункты.

## 5. Вкус не является сходимостью

Бесконечные ниты имитируют качество. После первого прохода —
открытые пункты и регрессия. Новый вкус = новый цикл, и только
если человек попросил.

## 6. Дедлок эскалируют, а не маскируют нитами

Пятая итерация без нуля блокеров — спор о контракте или о факте.
Это решение человека, не ещё один список «можно ещё лучше».

## 7. Деструкция необратима для агента

Store submit, force-push, wipe сохранений, отзыв билда, смена
signing identity — стоимость ошибки выше стоимости вопроса.
[gates.md](gates.md).

## 8. Тесты следуют за классом, не за привычкой

Hotfix доказывает, что сломанное больше не ломается.
Feature доказывает user paths / playable paths из спеки.
Пустой «добавь e2e» без класса — шум.

E2E в каноне = приёмочные сценарии из user paths + playtest-отчёт.
Раннер / устройство / Godot editor Run / export — факт проекта.

## 9. Две оси специально разделены

Процесс без домена даёт верный цикл и неверный код.
Домен без процесса даёт верный стиль и неверный объём работы.

## 10. Второй SDLC — развилка, которую нельзя скрыть

Новый домен со своими ролями, гейтами и router — развилка канона.
Её поднимают через [new-domain.md](new-domain.md) и evolve,
не через «у нас так принято в этом пакете».

## 11. GitHub — память команды и агентов

Issue, PR, label, milestone, Project, Action run, Release —
видимы следующему агенту. Чат — нет. Поэтому класс задачи и
ссылки на `spec.md` / `review.md` живут в Issue/PR.
