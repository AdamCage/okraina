# Дизайн и элаборация

Меню срезов для стадии элаборации. Не полный GDD. Аналитик выбирает
*зачем* срез, как диаграмму в process.

Шаблоны: [templates/DESIGN.feature.md](templates/DESIGN.feature.md),
при необходимости отдельные файлы lore/systems/UX/tech рядом со спекой.

## Когда нужен дизайн-пакет

| Ситуация | Минимум |
|---|---|
| Новая механика / режим | systems + UX + scope |
| Новый нарративный контент с правилами мира | lore (срез) + systems если влияет на геймплей |
| Новый технический контур (save, net, SDK, export) | tech design + platform/export notes |
| Новый экран / поток UI (Control-сцены) | UX (+ sequence, если есть сервис) |
| Чистый bugfix известного поведения | дизайн не обязателен |

Нет вопроса — нет файла. «Написать весь GDD» без feature-cycle —
запрещено.

## Меню срезов

| Срез | Вопрос | Содержание |
|---|---|---|
| Game design (цель) | Зачем игроку это? | Fantasy, loop, победа/поражение |
| Lore | Какие факты мира обязательны? | Канон мира, тон, что нельзя ломать |
| Systems | Какие правила? | Сущности, ресурсы, FSM, формулы (плейсхолдеры) |
| UX | Как игрок действует и видит? | Потоки, HUD, accessibility, input |
| Technical design | Как устроено под капотом? | Сцены, сигналы, ресурсы, autoload, риски |
| Scope | Что в slice / что нет? | Must / should / later, риски сроков |

## Связь со спекой

- `spec.md` — обещание поведения и user paths (process).
- Дизайн-пакет — *как* и *почему* внутри домена, без дубля спеки.
- Расхождение дизайн ↔ спека = блокер критика, не «потом согласуем».

## Критика дизайна

Критик ([../process/roles/critic.md](../process/roles/critic.md))
проверяет:

- выполнимы ли user paths на заявленных платформах;
- не раздут ли scope относительно slice;
- нет ли скрытых системных зависимостей;
- совместим ли lore/systems с уже принятым каноном проекта;
- есть ли perf/input риски mobile/PC.

Формат замечаний — секция analytics в `review.md` или `assumptions.md`.

## Чего не делать

- Не копировать чужой GDD целиком.
- Не фиксировать арт-пайплайн романaми без нужды контура.
- Не подменять `spec.md` дизайном (и наоборот).
