# spec.md — lore bible v0.1 (`docs/world`)

Источник истины **для контракта этого контура**: что считается каноном
мира «Окраина» на v0.1 и как агенты/авторы им пользуются.
Не код. Не полный GDD механик.

GitHub: https://github.com/AdamCage/okraina/issues/1

## Цель

Зафиксировать **lore bible v0.1** — живой SoT мира для top-down
action-roguelite ARPG «Окраина» (панельки, гигахрущ, бытовая нормальность
× пространственная/когнитивная аномалия, двачерская культура, глубокая
тайна без одного «это симуляция»-финала для игрока).

Контракт нужен, чтобы последующие `feature-cycle` / контент не ломали
тон, метафизику и разделение AUTHOR TRUTH / PLAYER KNOWLEDGE.

## Граница

### Входит

- Карта-схема Города (районы / оси, не тайловый план)
- Исторические эпохи (слой 1970–2025+)
- Организации (5–7 каркаса из разговора)
- Классификация аномалий / феноменов
- Устройство гигахруща как dungeon-метафоры мира
- Интернет-культура (имиджборда и роль в исследовании)
- Центральная тайна: семь конфликтующих версий + правило «нет одного
  ответа игроку»
- Разделение **AUTHOR TRUTH** vs **PLAYER KNOWLEDGE**
- Тон / эстетический инвариант («ЖЭК-объявление вместо крипипаст-крика»)
- User paths: как автор/агент и (позже) игрок взаимодействуют с лором

### Не входит

- Godot-проект, сцены, GDScript, балансные формулы, лут-таблицы
- Полный GDD combat / классов / метапрокачки (это отдельные контуры)
- Полный альбом документов/квестов/NPC-биографий
- Store / export / IAP
- Выбор движка (уже факт репо: Godot 4.7 + GDScript — вне этой спеки)

## Поведение (контракт для авторов и агентов)

1. Любой новый мировой факт сначала сверяется с `LORE.md` и
   `AUTHOR_TRUTH.md`. Конфликт с PLAYER-facing тоном или с AUTHOR TRUTH —
   блокер контента, не «пофиг, крипипаста».
2. Игроку **нельзя** выдать единственно верный финал вида
   «это симуляция / архив / …» как закрытие тайны. Допустимы артефакты,
   усиливающие несколько версий сразу.
3. Бытовая нормальность всегда первичнее «аномального спектакля».
   Официальный язык мира — ЖЭК, УК, объявления, треды, справки.
4. Знание делится слоями: слух → документ → личный опыт → кодекс.
   Не «Lore Entry №42 unlocked» как основной UX-обещание этой спеки
   (детальный UX кодекса — later / отдельный контур).
5. AUTHOR TRUTH читают только авторы/агенты с задачей на мир. В игровой
   текст, UI, диалоги и дроп-описания AUTHOR TRUTH не копировать
   дословно, пока спека контента явно не разрешит утечку.
6. Пробелы v0.1 помечены в `assumptions.md` / секциях OPEN в `LORE.md`.
   Их нельзя молча заполнять «удобным» новым каноном в том же классе.
7. Пока `AUTHOR_TRUTH.md` имеет STATUS UNSET: «сверка с AUTHOR TRUTH»
   = соблюдать правила письма и A21; **не** выбирать MODEL самостоятельно.
8. Жёсткие идентификаторы из разговора (борды, ЖК №17, эпохи, метрики
   гигахруща) приняты явно в assumptions A16–A19.

## User paths

Колонка **Exit v0.1**: входит ли путь в acceptance закрытия этого
`spec-only`.

| Путь | Актор | Успех | Ошибка | Exit v0.1 |
|---|---|---|---|---|
| P1 Consult SoT | Агент / автор контента | Находит ответ в `LORE.md` или явном OPEN; сверяет по A21 | Выдумывает новый жёсткий канон без `assumptions` / Issue | yes |
| P2 Write fragment | Автор предмета/документа/треда | Фрагмент усиливает ≥1 версию тайны и не ломает тон | Прямой спойлер AUTHOR TRUTH / дословная цитата author-шпаргалки / «УЖАС! МОНСТР!» тон | yes |
| P3 Player finds scrap | Игрок (будущий контур) | Получает противоречивое свидетельство; кодекс/дело пополняется | Игра объявляет «правильную теорию» | no (promissory) |
| P4 Board lead | Игрок (будущий контур) | Тред имиджборды даёт цель экспедиции; источник может врать | Все треды всегда истинны / всегда ложны | no (promissory) |
| P5 Author truth gate | Автор | Читает `AUTHOR_TRUTH.md`, пишет контент при UNSET/LOCKED по правилам файла | Сливает незакрытую AUTHOR TRUTH в player-facing текст | yes |

E2E/playtest кода в этом классе нет (раннера нет; класс `spec-only`).
