## 0. Pitch (один абзац)

**Окраина** — гигантский постсоветский **Город**, где школы, сетевые
магазины у дома, маршрутки, ЖЭК и ипотека существуют рядом с домами,
которые строят сами себя, подъездами без номера и станциями метро вне
схемы. Жители ведут себя так, будто всё нормально. **Мир больше сюжета
игрока** (product/genre frame — в `spec.md`, не здесь).

Визуальная формула (из разговора; **аналогия**, не канон топонима — A7/A20):

> узнаваемый постсоветский город 2000–2020-х (в разговоре как ориентир:
> Ростов/Москва/Екатеринбург) × бесконечная архитектура ×
> интернет-фольклор × серьёзная метафизика.

OPEN: конкретный топоним — [`assumptions` A7](assumptions.md).

## 1. Эстетический инвариант

**Не:** «УЖАС! АНОМАЛИЯ! МОНСТР!»  
**Да:** канцелярит и быт.

Пример тона:

> «В связи с повторным появлением лестничных площадок между 14-м и 15-м
> этажами просьба не оставлять там велосипеды.»

Рядом:

> «Сдам комнату девушке без животных. 17 этаж. Лифт до 16-го.»

Диссонанс обязателен: нормальный двор → окно с видимостью 74 км →
push «заказ передан курьеру».

NPC не обязаны мистически вещать. Типично:

> «Ты мусор можешь вынести?» / «Туда не ходи, связь плохо ловит.»

## 2. Карта Города (схема v0.1)

Не тайловая карта. Оси и типы мест из разговора.

```text
                    [горизонт: новые панели]
                              ↑
     ОКМЫШЛЕНКА  ←——  СПАЛЬНИКИ  ——→  ЦЕНТР / «СТАРЫЙ»
         │                │                │
         │           [ДВОРЫ]               │
         │                │                │
         └——————  ГИГАХРУЩ (Стена/Плита) ———┘
                        │
                   МЕТРО / ЭЛЕКТРИЧКА
                        │
              ОКЕИЗВЕСТНЫЕ СТАНЦИИ / ВЕТКИ
                        │
                    ОКОКРАИНЫ (?)
```

### Слои места (типы)

| Тип | Что есть в разговоре | OPEN |
|---|---|---|
| Квартира / дом игрока | Persistent hub-жизнь; «комната за кухней» как сюжетный крючок | Точный адрес, район |
| Спальники / дворы | Лавочки, бордюр, УК, пекарня на 1 этаже | Имена районов |
| Гигахрущ | Экспериментальный ЖК; см. §5 | Официальный индекс |
| Метро | Станции вне схемы | Схема линий |
| Электричка | Приезжает «куда рельсов не было» | Маршруты |
| Промзона | В раннем pitch run-структуры | Детали |
| Центр | В раннем pitch | Детали |
| Окраины | В названии / pitch | Есть ли край Города? |

### Топологические правила (player-facing, частичные)

- Город **чудовищно большой**; на горизонте всегда новые панели.
- Нумерация подъездов/этажей может пропускать номера; местные отрицают
  пропуск; старые фото его показывают.
- Войти в подъезд A, выйти через дни в районе «в 60 км» — возможно,
  даже если шли «вверх».
- GPS, велосипедный пробег и «ощущаемая длина» одного и того же дома
  **не обязаны совпадать**.

## 8. Центральная тайна (PLAYER KNOWLEDGE)

**Правило:** игроку не дают один правильный ответ.

Семь больших объяснений (все поддерживаются свидетельствами,
все конфликтуют):

1. **Расширение** — город растёт быстрее территории; начинает строить себя.
2. **Архив** — реконструкция из повреждённого госцифрового архива.
3. **Внешний мир есть** — сломана только эта зона; радио иногда прорывается.
4. **Мир закончился** — катастрофа не замечена; реальность держится бытом.
5. **Город всегда был таким** — «внешнее» = мифология/декорации.
6. **Ошибка измерения** — физика обычная; сломано восприятие топологии.
7. **Город живой** — сверхорганизм начинает себя осознавать.

Игрок может решить, что **несколько версий истинны сразу**.

### Сюжетный крючок №1 (из разговора)

Сообщение на старом форуме: «Ты уже находил комнату за кухней?»  
Позже появляется дверь → копия квартиры ~2003 → ПК → аккаунт игрока
с регистрацией **2002**, хотя персонаж младше.  
Подобных квартир много (старше/новее/чужие версии/вещи из будущих
забегов) — **не обязано** означать мультивселенную.

## 11. Связь с RPG (только мировой крючок)

Четыре параметра из разговора: **ТЕЛО / НЕРВ / ТЕХНИКА / ВОСПРИЯТИЕ**.  
ВОСПРИЯТИЕ: чем выше, тем больше «устройства мира» видно — и тем больше
угроз. Лестница «коридор → дверь → человек → никогда не существовал →
[невозможно отобразить]» — **мировой крючок** (A12); цифры, тики и
UI статов — не world-canon v0.1 (C5).
