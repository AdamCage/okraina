# ARCHITECTURE.md — run_floors (E3)

## Граница

| Модуль | Делает | Не делает |
|---|---|---|
| `game/resources/floors/*.tres` | Данные восьми пресетов | Не выбирает seed |
| `game/scripts/floor_preset.gd` | Тип ресурса | Не знает про забег |
| `game/scripts/floor_catalog.gd` | Грузит каталог в порядке спеки и считает `sequence(seed)` | Не меняет сцену |
| `GameState` | Хранит seed, длину, список id; `go_run` заполняет их до смены сцены | Не рисует этаж |
| `run_floor.gd` | Ставит пресет текущего индекса | Не бросает свой `randi` по планировке |
| `enemy.gd` | Два набора чисел по полю типа | Не выбирает, где стоять |

## Порядок на старте забега

1. `go_run` фиксирует seed и вызывает `sequence`.
2. Сцена этажа читает уже записанный id.
3. Выбор находки E2 открывается после расстановки, как раньше.
