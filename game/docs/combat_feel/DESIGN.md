# DESIGN.md — combat_feel

Спека: [`spec.md`](spec.md).

## Цель и fantasy

Этаж перестаёт быть бегом сквозь касательный урон. Удар дома
сначала объявляет себя, и от него можно уйти одним шагом.

## Loop

1. Враг догоняет и замирает.
2. Янтарная подготовка.
3. Шаг в сторону или принятый удар.
4. Ответная атака игрока, как раньше.

## Systems

| Сущность | Правило |
|---|---|
| Player dodge | По `dodge`: скорость 520 на 0.16 с вдоль последнего взгляда. Перезарядка 0.70 с с кадра нажатия, повтор игнорируется. Неуязвимость: 0.16 с, либо до удара текущей подготовки (не дольше 0.50 с), если нажатие застало подготовку в зоне |
| Player attack | Без изменений: 25 урона, кулдаун 0.4 с, зона AttackArea |
| Enemy | Фазы chase → windup 0.50 с → один удар 18 → recover 0.40 с. В windup и recover не бежит |
| Урон игрока | `take_damage` не снимает HP, пока действует неуязвимость: 0.16 с шага без подготовки, либо до удара подготовки, которую нажатие застало (не дольше 0.50 с). Конец шага сам по себе закрытие не снимает |

FSM врага — в `spec.md`.

## UX

- Вход: тот же забег, сцена `run_floor`
- Поток: янтарный враг → Shift → шаг; удар без шага красит игрока красным
- Пустое состояние: враг далеко — подготовки нет, Shift всё равно делает шаг
- Input PC: Shift, одна кнопка. Мышиный прицел шага нет
- Mobile: не в этом срезе

## Lore

Тон ЖЭКа и тайна не меняются. Бой не объявляет теорию мира.

## Technical design

- `player.gd`: шаг и ранний выход из `take_damage`
- `enemy.gd`: фазы вместо `_touch_acc`
- `project.godot`: действие `dodge`
- Сигнал новой шины не нужен
- Save нет

## Scope

| Must | Should | Later |
|---|---|---|
| CF1–CF5, числа из спеки | Отдельная полоска телеграфа | Звук, анимации, touch, второй враг |

Вертикальный срез боя: прежние три этажа, один тип врага на каждом, шаг отнимает ровно один подготовленный удар. Число этажей не меняется.

## Платформы

- PC: клавиша Shift
- Mobile: одна будущая кнопка на `dodge`
- Budget: чисел FPS нет до E10
