| ID | Допущение | Статус | Кто снял |
|---|---|---|---|
| A1 | Защитное действие одно: шаг по взгляду с неуязвимостью на время шага. Не блок щитом и не рывок с прицелом мыши. | accepted | программа E1: одно действие; форма ввода — одна кнопка (эта спека) |
| A2 | Клавиша — Shift, действие InputMap `dodge`. Пробел остаётся атакой. | accepted | эта спека: не отбирать `attack` |
| A3 | Касательный урон 12/с снят. Иначе CF2 («один удар») не отличить от старого DPS. | accepted | выход CF2 |
| A4 | Без подготовки неуязвимость равна шагу (0.16 с). Нажатие в подготовке закрывает один этот удар и не длится дольше 0.50 с. Перезарядка 0.70 с идёт с кадра нажатия и повтор не принимает. | accepted | CF1: ранний Shift всё ещё снимает объявленный удар; удержание не даёт вечную неуязвимость |
| A5 | Янтарный цвет визуала — достаточный телеграф. Отдельная полоска подготовки и hitstop не входят. | accepted | программа E1: вспышка или hitstop, одно из двух |
| A6 | Подсказка «нажмите Shift» на экране не ставится. Клавиша записана в спеке; голос первой минуты — этап E10. | accepted | граница E1 / E10 |
| A7 | Числа из таблицы спеки — стартовый контракт проверки. Баланс «приятно» не блокирует выход, пока CF1–CF3 зелёные. | open | — |
| A8 | B1–B3 не участвуют: бой не выбирает версию тайны. | accepted | программа |
