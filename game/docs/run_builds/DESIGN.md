# DESIGN.md — run_builds

Спека: [`spec.md`](spec.md).

## Цель и fantasy

Этаж начинается с чужой вещи на тумбочке. Берёшь одну — и этот забег
уже другой: рука тяжелее, ноги быстрее или шаг короче.

## Loop

1. Вход на этаж.
2. Три строки, бой стоит.
3. Клавиша 1, 2 или 3.
4. Бой E1 с новым статом. На следующем этаже взятое ещё с тобой.

## Systems

| Сущность | Правило |
|---|---|
| Пул | 10 id из таблицы спеки |
| Тройка | Без повторов. Сначала из ещё не взятых |
| Применение | Пересчёт списка в `GameState`, затем живой игрок |
| Лечение | Только в кадр выбора |
| Заморозка | `floor_offer_open` гасит `_physics_process` игрока и врага |

## UX

- Вход: поверх этажа, три кнопки
- Поток: читать строку эффекта и нажать 1/2/3
- Ошибка: четвёртой кнопки «ничего не брать» нет
- Input PC: клавиши 1, 2, 3. Мышь по кнопке тоже берёт ту же находку
- Mobile: не в этом срезе

## Lore

Тон тумбочки и подъезда. Не кодекс и не вердикт о Городе.

## Technical design

- `offer_catalog.gd` — таблица
- `offer_panel.gd` — слой выбора
- `GameState` хранит список до конца забега
- `player.gd` читает пересчёт в `apply_build`
- Save нет

## Scope

| Must | Should | Later |
|---|---|---|
| RB1–RB4, пул 10, заморозка | Иконки находок | Убийства как второй триггер, редкости, сеты |

Вертикальный срез: три этажа как сейчас, на каждом один обязательный выбор.

## Платформы

- PC: 1, 2, 3
- Mobile: три будущие кнопки
- Budget: не в этом срезе
