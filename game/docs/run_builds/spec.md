# spec.md — run_builds (E2)

Источник истины выбора находки **внутри** забега.
Программа: [`docs/program/spec.md`](../../../docs/program/spec.md) этап E2.
Бой: [`../combat_feel/spec.md`](../combat_feel/spec.md).

## Цель

В начале каждого этажа игрок берёт одну из трёх находок.
Находка сразу меняет удар, скорость, здоровье или шаг этого же забега.

## Граница

### Входит

- Один тип предложения: находка этажа. Пул из 10.
- В начале этажа — три разных id. Пока выбор не сделан, игрок и враги не действуют.
- Клавиши 1, 2, 3. Для будущего touch это три отдельные кнопки.
- Оси только ТЕЛО и НЕРВ. НЕРВ включает перезарядку и скорость шага из E1.
- Выбранное копится до конца забега и заново применяется к игроку на следующем этаже.
- Headless: выбор меняет обещанный стат.

### Не входит

- Лут с пола, сеты, крафт, архетипы, статы ТЕХНИКА и ВОСПРИЯТИЕ
- Выбор по числу убийств
- Объяснение тайны мира
- Замена meta-boon после смерти или выхода: он остаётся наградой на **следующую** попытку

## Поведение

1. `go_run` обнуляет находки этого забега.
2. Сцена этажа открывает выбор до боя. На экране три названия и короткая бытовая строка эффекта.
3. 1 / 2 / 3 или `pick_offer(index)` берёт соответствующую находку и закрывает выбор.
4. Пока выбор открыт, физика игрока и врагов не идёт, в зону выхода войти нельзя.
5. Эффект применяется сразу к живому игроку и к `GameState`.
6. Следующий этаж того же забега помнит уже взятое и снова даёт новый выбор.
7. Уход со этажа вызовом `advance_floor` / `finish_extract` без выбора не применяет невзятые три. Игроку этот уход закрыт, пока выбор открыт.
8. Смерть и выход не зависят от находки. Следующий `go_run` снова с пустым списком.
9. Тексты находок не говорят, что случилось с Городом.

Пул (ровно эти 10):

| id | Ось | Текст | Эффект |
|---|---|---|---|
| brick | ТЕЛО | Кирпич в рукаве | +12 урона атаки |
| sweater | ТЕЛО | Второй свитер | +25 к максимуму HP, затем +25 текущего, не выше нового максимума |
| short_swing | ТЕЛО | Короткий замах | кулдаун атаки ×0.8, не ниже 0.20 с |
| another_brick | ТЕЛО | Ещё кирпич | +8 урона атаки |
| tap_water | ТЕЛО | Вода из-под крана | +20 к максимуму HP, затем лечение до этого максимума |
| slippers | НЕРВ | Домашние тапки | скорость ×1.25 |
| habit | НЕРВ | Привычка уходить | перезарядка шага −0.20 с, не ниже 0.25 с |
| long_stride | НЕРВ | Широкий шаг | скорость шага +140 |
| hurry | НЕРВ | Опаздываю | скорость ×1.15 |
| shoulder | НЕРВ | Плечо уже ушло | перезарядка шага −0.15 с, не ниже 0.25 с |

Статы складываются по списку взятого: урон суммой, скорость произведением множителей, кулдауны как в таблице. Прибавка максимума HP пересчитывается из списка. Прибавка текущего HP срабатывает один раз в момент выбора и только после того, как максимум уже увеличен этой находкой. На следующем этаже текущее HP заново не лечится.

Три предложения — случайные id, которых ещё нет в списке взятого. Если оставшихся меньше трёх, добивать из всего пула, без повтора внутри одной тройки.

## User paths

| Путь | Актор | Успех | Ошибка |
|---|---|---|---|
| RB1 Выбор | Игрок | Этаж открылся → три строки → 1/2/3 → бой пошёл, стат из таблицы этой id уже другой | Выбор не закрывается или стат прежний |
| RB2 Следующий этаж | Игрок | Находка первого этажа всё ещё на игроке второго | Список обнулился на жёлтой зоне |
| RB3 Смерть и выход | Игрок | HP 0 → `death`; выход с последнего этажа → `extract` | Находка ломает переход |
| RB4 Новый забег | Игрок | Следующий `go_run` без прошлых находок | Статы прошлого забега утекли |
