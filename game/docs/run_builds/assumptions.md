# assumptions.md — run_builds (E2)

| ID | Допущение | Статус | Кто снял |
|---|---|---|---|
| A1 | Триггер — начало каждого этажа, не каждые N убийств. Программа разрешает один из двух. | accepted | эта спека, путь RB1 на каждом этаже |
| A2 | Оси — ТЕЛО и НЕРВ. Шаг E1 меняют находки НЕРВ `habit`, `long_stride`, `shoulder`. Отдельной третьей оси нет. | accepted | программа: две оси из трёх названных |
| A3 | Пока выбор открыт, бой заморожен. Иначе находка не успевает изменить забег до удара. | accepted | выход RB1 |
| A4 | `advance_floor` без выбора не применяет тройку. Игрок до выбора до выхода не доходит. Смоук прежнего цикла может сменить этаж, не нажимая 1/2/3. | accepted | регрессия `full_smoke` |
| A5 | Тексты — быт. Ни одна строка не выбирает версию тайны. | accepted | программа E2 и LORE |
| A6 | Boon после забега не заменяется находкой и суммируется с ней на следующей попытке, если игрок его взял. | accepted | граница «не входит» |
| A7 | Случай тройки не фиксируется сидом в этой спеке. Проверка читает выпавшие id и сверяет их эффект, а не конкретный набор. | open | — |
