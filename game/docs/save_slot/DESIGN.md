# DESIGN.md — save_slot (E4)

Игрок не видит меню сохранений и слова «слот».

Квартира после нового запуска показывает ту же дверь, ту же строку ЖЭКа и тот же `/pod/`, что были при уходе.
Если папка с записью не читается, вместо прежней строки ЖЭКа стоит: «Папка с документами не читается. Завели новую карточку жильца.» Двери за кухней в этом случае нет. Это карточка заново, не объяснение Города.
