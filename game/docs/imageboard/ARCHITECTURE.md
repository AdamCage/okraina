# ARCHITECTURE.md — imageboard (E5)

| Модуль | Делает | Не делает |
|---|---|---|
| `game/scripts/board_catalog.gd` | `threads_for` и модификатор по id | Не пишет файл |
| `game/scripts/board_panel.gd` | Список, тело, B и «проверить» | Не меняет статы сам |
| `GameState` | Хранит `lead_id`, `pick_lead`, отдаёт числа в `apply_build` | Не сочиняет текст треда |
| `slot_store.gd` | Версия 2, миграция целого файла версии 1 | Не считает версию 1 порчей |
| `apartment_hub.gd` | Открывает борду и по-прежнему пишет слот в конце `_ready` | Не стирает выбор при открытии |

`board_feed` остаётся короткой строкой хаба из прошлого контура. Треды борды строятся из трёх полей итога, не из этой строки.
